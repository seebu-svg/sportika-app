SportPhoto prefers bundled assets in `assets/images/sports/`, then uses the
credited remote photograph, then a fixed-size sport-specific unavailable state.
Sources request 1200px compressed images; decoded image width is capped at
1600px. The local download command is `python3 tool/fetch_sport_photos.py`.
