# Sport photography assets

Expected filenames: `cricket.jpg`, `padel.jpg`, `futsal.jpg`, `badminton.jpg`.
These are preferred by SportPhoto, with the credited HTTPS sources as a fallback.
See ../../PHOTO_CREDITS.md for source pages and licenses.

Run `python3 tool/fetch_sport_photos.py` on a network-enabled machine to populate
this folder with source-optimized 1200px JPEG photographs. No generated artwork
or placeholder photographs are substituted for a sport.
